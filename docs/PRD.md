## 1. 專案概述

### 1.1 背景與動機

隨著高齡化與少子化日趨嚴重，獨居老人的數量逐漸增加。這些長者常因無人照顧、慢性病纏身，加上不熟悉新興通訊設備，在發生特殊狀況時無法即時求助，可能過了數天甚至數月才被發現異狀。

為了能**每日確認獨居老人的生活情況**，我們開發一套專屬獨居老人使用的 Web 系統——「獨居老人生活管家」，透過簡單的介面設計讓長者能輕鬆操作，同時讓家屬與護工即時掌握老人的生活狀態。

### 1.2 目標用戶

| 角色 | 描述 |
| :--- | :--- |
| 獨居老人（長者） | 需要被照顧，但無法無時無刻受到照顧的族群。是系統的主要使用者，操作介面需極度簡化。 |
| 家屬 | 肩負照顧獨居老人的責任，但因工作或距離等原因無法時刻陪伴。需要遠端掌握長者狀況。 |
| 護工 | 提供老人生活護理的專業人員。需要瞭解長者的日常狀態以安排照護計畫。 |

### 1.3 核心價值主張

- **每日安全確認**：透過簡單的「每日回報」機制，讓家屬隨時知道長者是否安好。
- **用藥不遺忘**：系統化的事項提醒功能，確保長者按時服藥、完成日常事務。
- **緊急即時求助**：一鍵緊急按鈕，在意外發生時第一時間通知家屬。
- **操作極簡化**：介面針對長者設計，大按鈕、大字體、簡單流程。

### 2.2 使用者故事（User Stories）

#### F-01 事項提醒

| # | 使用者故事 |
| :--- | :--- |
| US-01 | 作為**家屬**，我希望能**為長者新增提醒事項（如用藥時間、回診日期）**，以便**長者不會忘記重要事務**。 |
| US-02 | 作為**長者**，我希望在**設定的時間看到提醒通知**，以便**我知道該做什麼事**。 |
| US-03 | 作為**家屬**，我希望能**查看、編輯和刪除已設定的提醒**，以便**隨時調整長者的日程**。 |
| US-04 | 作為**長者**，我希望在**完成提醒事項後按下「已完成」按鈕**，以便**家屬知道我已完成**。 |

#### F-02 每日回報

| # | 使用者故事 |
| :--- | :--- |
| US-05 | 作為**長者**，我希望每天**按下「我很好」按鈕進行每日回報**，以便**家屬知道我今天安好**。 |
| US-06 | 作為**家屬**，我希望能**查看長者的每日回報紀錄**，以便**掌握長者近期的生活狀況**。 |
| US-07 | 作為**家屬**，我希望在**長者超過一定時間未回報時收到警示**，以便**我能主動關心**。 |

#### F-03 緊急按鈕

| # | 使用者故事 |
| :--- | :--- |
| US-08 | 作為**長者**，我希望在**遇到緊急狀況時按下一個大按鈕**，以便**系統立即通知我的家屬**。 |
| US-09 | 作為**家屬**，我希望在**長者按下緊急按鈕後立即收到警示通知**，以便**我能儘速採取行動**。 |
| US-10 | 作為**家屬**，我希望能**查看緊急通報的歷史紀錄**，以便**追蹤過去發生的緊急事件**。 |

#### F-04 使用者管理

| # | 使用者故事 |
| :--- | :--- |
| US-11 | 作為**使用者**，我希望能**註冊帳號並選擇角色（長者/家屬/護工）**，以便**使用對應的功能**。 |
| US-12 | 作為**使用者**，我希望能**登入系統**，以便**看到屬於自己的資料**。 |
| US-13 | 作為**家屬**，我希望能**綁定我照顧的長者帳號**，以便**接收該長者的通知與回報**。 |

#### F-05 家屬/護工儀表板

| # | 使用者故事 |
| :--- | :--- |
| US-14 | 作為**家屬**，我希望在**登入後看到儀表板**，顯示**長者今日是否已回報、提醒完成狀況、是否有緊急通報**。 |
| US-15 | 作為**護工**，我希望能**查看負責的所有長者的狀態總覽**，以便**有效安排照護工作**。 |

## 3. 非功能需求（Non-functional Requirements）

| 類別 | 需求描述 | 具體標準 |
| :--- | :--- | :--- |
| 效能 | 系統要能穩定且長期運行 | 頁面載入時間不超過 3 秒 |
| 安全性 | 資料傳輸需加密，防止個資洩漏 | 密碼使用雜湊儲存（如 bcrypt），使用 Flask session 管理登入狀態 |
| 易用性 | 使用簡單幾個按鈕來操作 | 長者介面最多 3 個主要按鈕，字體不小於 24px |
| 可維護性 | 程式碼有清楚的結構與註解 | 使用 MVC 架構，函式需有 docstring |
| 相容性 | 支援主流瀏覽器 | 支援 Chrome、Edge、Safari 最新版本 |

### 技術限制

- **前端**：HTML / CSS / JavaScript（純前端，無框架）
- **後端**：Python + Flask
- **模板引擎**：Jinja2（由 Flask 渲染 HTML 頁面）
- **資料庫**：SQLite（使用 sqlite3 模組）
- **不採用前後端分離**：頁面由 Flask + Jinja2 一起渲染
